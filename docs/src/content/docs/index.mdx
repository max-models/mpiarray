## What is included

<CardGrid>
	<Card title="Domain decomposition" icon="puzzle">
		`DomainDecomposition` splits a Cartesian grid over the MPI ranks: process grid, neighbours, owned index ranges and subdomains.
	</Card>
	<Card title="Distributed arrays" icon="open-book">
		`DistributedArray` adds ghost cells, halo fill and accumulation, gathers, global reductions and NumPy operators.
	</Card>
	<Card title="NumPy or CuPy" icon="rocket">
		Arrays come from cunumpy, so the same code runs on the CPU or the GPU, with or without CUDA-aware MPI.
	</Card>
	<Card title="API reference" icon="setting">
		Every module, class and function is documented from the docstrings.
	</Card>
</CardGrid>
