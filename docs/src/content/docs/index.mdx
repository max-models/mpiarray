## What is included

<CardGrid>
	<Card title="Like NumPy" icon="open-book">
		`mpa.array`, `mpa.zeros`, `mpa.arange`, … create arrays split over the MPI ranks, with operators, ufuncs and reductions as in NumPy.
	</Card>
	<Card title="Halo cells" icon="puzzle">
		Optional halo cells per axis, updated from the neighbours for stencils or accumulated into them after particle deposition.
	</Card>
	<Card title="NumPy or CuPy" icon="rocket">
		Arrays come from cunumpy, so the same code runs on the CPU or the GPU, with or without CUDA-aware MPI.
	</Card>
	<Card title="With or without MPI" icon="setting">
		Without an MPI launcher the same script runs serially, without mpi4py.
	</Card>
</CardGrid>
