Work through these notebooks in order, or jump to a topic. Each tutorial page includes
its code and a downloadable notebook; executed builds also show the outputs.

- [Distributed arrays](/mpiarray/tutorials/distributed-arrays/) — create arrays, work with local blocks, and exchange halos.
- [Heat equation](/mpiarray/tutorials/heat-equation/) — evolve a distributed field with a finite-difference stencil.
- [Particles](/mpiarray/tutorials/particles/) — distribute particles and deposit their contributions on a grid.
- [Using physical units](/mpiarray/tutorials/units/) — combine compatible quantities, compute energy density, and reduce to unit-bearing scalars.
- [Building, reducing and saving arrays](/mpiarray/tutorials/working-with-data/) — assemble rank-local data, reduce it, select parts, and save it.

See [Building the docs](/mpiarray/development/docs/) to execute the notebooks locally
and learn about the cell tags that control what is shown.
